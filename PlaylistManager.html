The bookmarklet runs directly on the Apple Music page — no CORS issues, no auth needed. It reads the track list from the DOM and copies it to your clipboard.

🎵 Extract Apple Music Tracks
or click to copy the code and create a bookmark manually
  • 1Drag the button above to your browser's bookmarks bar (View → Show Bookmarks Bar if hidden)
  • 2Open music.apple.com and navigate to your playlist — scroll so all tracks are visible
  • 3Click the 🎵 Extract Apple Music Tracks bookmark — it will copy all tracks to your clipboard
  • 4Switch to the ✏️ Smart Paste tab and paste — or use Bulk Import in the sidebar
⚠ Apple Music uses a virtual list — if your playlist is long, scroll slowly to the bottom first so all tracks render before running the bookmarklet.

Use Apple Music's built-in sharing to copy the full track list as text, then paste it here.

🌐 Apple Music Web Player
  • 1Open the playlist at music.apple.com and sign in
  • 2Click the first track, then Ctrl+A / ⌘A to select all
  • 3Press Ctrl+C / ⌘C to copy
  • 4Paste into Smart Paste tab — the parser handles all Apple formats

Paste anything — Apple's "Copy Song List", numbered lists, Artist – Title lines, raw text. The parser handles all formats automatically.
